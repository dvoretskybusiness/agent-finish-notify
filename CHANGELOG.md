# Changelog

## 1.3.1 — 2026-11-11

- Заготовка короткого ответа после включения: не больше шести строк, без разделов и пересказа
  возможностей.
- Запрет на выдуманный мастер настройки: отправка ничего не спрашивает, каналы выбираются один раз.
- Каналы сохраняются в конфиг (`set-channels`) и называются в ответе точно; `enable` печатает порог
  и каналы.

## 1.3.0 — 2026-11-11

- Проверка обновлений: `arm` раз в сутки спрашивает последний релиз на GitHub и возвращает `update`.
- Предложение обновиться с заметками релиза; отказ запоминается командой `decline-update`.
- Процедура обновления вынесена в `references/update.md`.

## 1.2.5 — 2026-11-11

- `check` больше не молчит при незапущенном таймере: считает от последней активности и возвращает
  `SEND … auto` или `SKIP … auto`.
- `NOTARMED` вместо `NOSTART`, когда данных о последней активности нет.
- `status` показывает `taskActive` и предупреждение, если задача не начата.
- После `SKIP` обязателен `done`: задача закрывается, таймер не наследуется.

## 1.2.4 — 2026-11-11

- Название категории вынесено в шапку уведомления осознанно: подпись берётся из декларации,
  `source.title` её не меняет.
- Шаблон декларации переименован в «Агент Chatium code: уведомление».

## 1.2.3 — 2026-11-10

- `source.title` — название категории; событие пишется только в `title` сообщения.
- Поправка: повторный `id` обновляет запись в центре, но письмо может уйти ещё раз.

## 1.2.2 — 2026-11-10

- Ссылка в уведомлении ведёт на `/app/dev/code` — Chatium Code с меню аккаунта.

## 1.2.1 — 2026-11-10

- Уведомление о вопросе решается в момент вопроса по порогу 30 секунд с последнего сообщения.
- Команда `ask`.

## 1.2.0 — 2026-11-10

- Настройка вынесена в `references/setup.md`, тело навыка сокращено.
- Правила для сообщений по ходу работы.
- Откат при неудачной сборке декларации.

## 1.1.0 — 2026-11-10

- Первая публичная версия: уведомление о завершении задачи, каналы, порог, вопросы.
