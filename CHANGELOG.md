# Changelog

## 2.0.7 — 2026-11-14

- Время задачи считается от сообщения пользователя, а не от хода.
- Пока идут фоновые задачи, уведомлений нет — ни серверных, ни браузерных.
- Согласие на платную генерацию: если карточка ждёт ответа 8 секунд, приходит «Нужен ответ».
- Клиент следит за карточкой согласия и сообщает серверу, что ответ дан.

## 2.0.6 — 2026-11-14

- Исправлены сниппеты `chatium exec`: `ctx.user` проверяется на undefined — из-за этого не уходили уведомления в Telegram и не грузились каналы.
- Ошибки отправки пишутся в `$DSH_HOME/notify-panel.log`.
- Отложенная отправка: если вкладка «умерла» без сигнала, уведомление уйдёт через 50 секунд.
- Панель: таймаут запроса каналов и текст ошибки вместо вечного «Загружаю…».

## 2.0.5 — 2026-11-12

- В навык и README добавлен снимок: где находится колокольчик в шапке сессии.
- Убраны упоминания активации через «+» из основного описания.

## 2.0.4 — 2026-11-12

- Уточняющий вопрос агента (`ask_user_question`) теперь даёт «Нужен ответ» с текстом вопроса.
- Если уйти, пока вопрос ждёт ответа, уведомление догоняет.
- Если агент отправил уведомление сам, дубля нет.

## 2.0.3 — 2026-11-12

- Установщик плагина больше не ломает профиль с комментариями и `[]`: пустота определяется по содержимому без комментариев, комментарии сохраняются, блок дописывается корректно.
- Исправлено форматирование при добавлении к профилю с другими плагинами.

## 2.0.2 — 2026-11-12

- Уведомление о завершении цитирует итог задачи из ответа агента.
- Если агент уже отправил уведомление сам (старая схема), плагин не дублирует.

## 2.0.1 — 2026-11-12

- В панели появились каналы: центр, Telegram, почта — со статусами и ссылками, если не настроены.

## 2.0.0 — 2026-11-12

- Навык стал установщиком и настройщиком: уведомления отправляет плагин, а не агент.
- Руководство по ручному режиму вынесено в references/fallback.md.
- README переписан под плагин, панель и каналы.

- Центр уведомлений можно выключить: остаётся только Telegram.

## 1.4.0 — 2026-11-12

- Плагин в составе навыка: колокольчик, панель настроек, локальные уведомления.
- Серверная часть плагина: уведомления о завершении и о запросе прав при закрытой вкладке.
- Установка без перезапуска: клиент работает сразу после обновления вкладки, серверная часть

## 1.3.2 — 2026-11-11

- «Правило №1» в начале навыка: перед каждым `ask_user_question` — сначала `ask`, иначе человек
  будет молча ждать.
- `enable` больше не запускает таймер: отсчёт начинает `arm`, поэтому длительность задачи считается
  от её начала, а не от включения навыка.
- `ask` печатает готовый `id` вопроса — собирать вручную не нужно.
- `enable` печатает напоминание про вопросы.

## 1.3.1 — 2026-11-11

- Заготовка короткого ответа после включения: не больше шести строк, без разделов и пересказа
  возможностей.
- Запрет на выдуманный мастер настройки: отправка ничего не спрашивает, каналы выбираются один раз.
- Каналы сохраняются в конфиг (`set-channels`) и называются в ответе точно; `enable` печатает порог
  и каналы.

## 1.3.0 — 2026-11-11

- Проверка обновлений: `arm` раз в сутки спрашивает последний релиз на GitHub и возвращает `update`.
- Предложение обновиться с заметками релиза; отказ запоминается командой `decline-update`.
- Процедура обновления вынесена в `references/update.md`.

## 1.2.5 — 2026-11-11

- `check` больше не молчит при незапущенном таймере: считает от последней активности и возвращает
  `SEND … auto` или `SKIP … auto`.
- `NOTARMED` вместо `NOSTART`, когда данных о последней активности нет.
- `status` показывает `taskActive` и предупреждение, если задача не начата.
- После `SKIP` обязателен `done`: задача закрывается, таймер не наследуется.

## 1.2.4 — 2026-11-11

- Шаблон декларации переименован в «Агент Chatium code: уведомление».
